# AGENTS.md

This repository's agent/assistant guidance is maintained in a single canonical file:
**[CLAUDE.md](CLAUDE.md)**.

It covers the build/test/run commands (including the non-obvious ones — single-test runs and
the headless `--transcribe` pipeline), the pipeline architecture, and the whisper.cpp/Metal
vendoring scheme. Read it before working in this repo.

If you add project guidance, edit `CLAUDE.md` so there's one source of truth; keep this file a
pointer, not a copy.
